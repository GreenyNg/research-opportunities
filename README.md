# AI Research Internship Deadlines (2026)

A curated iCalendar (`.ics`) file containing key application deadlines, requirements, and links for top research internships and fellowships in AI, Machine Learning, and Computer Science.

### Features
- Pre-configured reminder alarms (14 days and 3 days before each deadline).
- Event descriptions populated with requirements, eligibility criteria, and application links.
- Compatible with Google Calendar, Apple Calendar, Outlook, and other CalDAV clients.

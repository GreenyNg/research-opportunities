A curated, automatically updating iCalendar (`.ics`) feed and opportunity repository tracking key application deadlines, requirements, and direct application links for top global research internships, pre-docs, and fellowships across Artificial Intelligence, Machine Learning, and Computer Science.

Designed especially for undergraduate and graduate researchers targeting tracks like **Data Management, Recommendation Systems, Machine Learning Systems, and AI Alignment**.
